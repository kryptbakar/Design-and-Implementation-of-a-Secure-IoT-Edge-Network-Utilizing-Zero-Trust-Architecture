----------------------------------------------------------------
  HOW TO INSTALL CISCO PACKET TRACER
----------------------------------------------------------------

  Step 1: Go to https://www.netacad.com
  Step 2: Register or log in with a free Cisco NetAcad account
  Step 3: Navigate to "Resources" > "Download Packet Tracer"
  Step 4: Download the installer for your operating system
           (Windows / Linux / macOS)
  Step 5: Run the installer and follow the on-screen instructions
  Step 6: Launch Packet Tracer and log in with your NetAcad account

----------------------------------------------------------------
  HOW TO OPEN & RUN THE PROJECT
----------------------------------------------------------------

  Step 1: Launch Cisco Packet Tracer

  Step 2: Go to File > Open
          Navigate to the project folder and select:
          "mehdi_project.pkt"

  Step 3: The network topology will load automatically.
          You will see the full IoT Edge Network with
          Zero Trust Architecture configured.

  Step 4: To run the simulation:
          - Click the "Simulation" tab at the bottom right
            (or press ALT + SHIFT + S)
          - Click "Play" to begin the simulation
          - Use "Add Simple PDU" (envelope icon) to send
            test packets between devices

  Step 5: To test specific protocols (ARP, ICMP, OSPF):
          - In Simulation mode, use Event List filters to
            select the protocol you want to observe
          - Send a ping between devices to trigger ICMP
          - Observe routing tables to verify OSPF convergence
          - Check ARP tables for MAC resolution

  Step 6: To verify Zero Trust policies:
          - Click on any device (router/switch/IoT device)
          - Go to "Config" or "CLI" tab
          - Review access control lists (ACLs) and
            security policies applied

----------------------------------------------------------------
  TROUBLESHOOTING
----------------------------------------------------------------

  - If the .pkt file does not open, ensure your Packet Tracer
    version is 8.2 or later (older versions may not support
    all features used in this project).

  - If devices show as inactive (red links), switch to
    Realtime mode and wait for the network to converge
    (approximately 30-60 seconds for OSPF convergence).

  - If prompted to log in when opening Packet Tracer,
    use your Cisco NetAcad account credentials.

----------------------------------------------------------------
  NOTES
----------------------------------------------------------------

  - This project simulates a secure IoT edge network using
    Zero Trust Architecture principles including:
      * Network segmentation
      * Access control policies (ACLs)
      * Encrypted communication paths
      * OSPF dynamic routing
      * ARP and ICMP verification

  - No physical hardware is required. All testing is done
    within the Cisco Packet Tracer simulation environment.
