Secure IoT Edge Network — Zero Trust Architecture

Designing and implementing a Zero Trust security model for IoT edge networks, built and validated in Cisco Packet Tracer.

Status: Complete License: MIT Tool: Cisco Packet Tracer 8.2+

About

This project presents the full design and implementation of a secure IoT edge network built on Zero Trust Architecture principles — "never trust, always verify" applied to every device and communication path. The topology combines IoT devices, edge gateways, and servers behind OSPF-based dynamic routing, with access control lists and device-level authentication enforced at every network boundary. Protocol behaviour (ARP, ICMP, OSPF) was captured and measured directly in Cisco Packet Tracer to validate that the security policies hold under real traffic.

Highlights

  • Zero Trust enforcement — continuous verification of every network communication, no implicit trust between segments.
  • Micro-segmentation — IoT devices isolated into dedicated VLANs / security zones, separate from core infrastructure.
  • ACL-based access control — granular access control lists applied at every router and gateway boundary.
  • OSPF dynamic routing — convergence and neighbor relationships verified under the applied security policies.
  • Protocol-level testing — ARP resolution, ICMP connectivity, and OSPF routing all captured and documented with screenshots.
  • Quantitative performance analysis — latency, throughput, and security-overhead metrics collected and exported to CSV.
